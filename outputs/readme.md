# Generated outputs

This directory contains the static and interactive visualisations generated by the Jupyter notebook `Glagoljicna_bastina_vizualizacije.ipynb`.
All outputs are based on metadata describing Glagolitic manuscripts from the Zadar Archdiocese, originating from the GlagoLab catalogue of the Centre for Research in Glagolitism, University of Zadar.

## Static visualisations

- `glag_kronologija.png` — chronological distribution of manuscripts by century and 25-year period
- `glag_vrste_dokumenata.png` — distribution of document types
- `glag_heatmapa.png` — heatmap of place of origin × document type
- `glag_stanje.png` — condition of the binding and text block
- `glag_uvez.png` — binding materials and binding types
- `glag_vodeni_znakovi.png` — watermark presence and most frequent motifs
- `glag_wordcloud.png` — word cloud of manuscript titles

## Interactive visualisations

- `glag_karta.html` — interactive map of manuscripts by place
- `glag_karta_heatmap.html` — interactive geographic density heat map
- `glag_vrste_po_mjestima.html` — interactive chart of document types by place
- `glag_vremenska_crta.html` — interactive timeline of manuscript date spans by document type

## Reproducibility

All files in this directory can be regenerated by running all cells in:

`Glagoljicna_bastina_vizualizacije.ipynb`

The notebook contains the complete workflow for data processing and visualisation.
The metadata used by the notebook are also available separately in:

`data/glagolab_zadar_archdiocese_metadata.csv`
